## Páginas de demonstração

Esses links **não** conectam ao Ollama ou ao PC por conta própria:

- [Yuna Anime 2D articulada](https://raw.githack.com/SrHenriqueBR/Projeto-Yuna/main/docs/yuna-preview.html) — reações e retrato original.
- [Yuna 3D geométrica no navegador](https://raw.githack.com/SrHenriqueBR/Projeto-Yuna/main/docs/yuna-3d-viva.html) — movimentos demonstrativos via WebGL.

As páginas públicas são servidas pelo domínio de prévia de terceiros
`raw.githack.com`. O chat real e o 3D VRM com modelo próprio
são recursos locais, conforme as orientações no aplicativo.
